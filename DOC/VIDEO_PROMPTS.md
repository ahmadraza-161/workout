## How to use

1. In Google Flow, choose **Text to Video**, the best-quality Veo model available, **16:9 landscape**, 8 seconds.
2. Copy one prompt exactly as written. Generate 2–4 versions and keep the one with the clearest, most correct form.
3. Download at 720p or 1080p. Do not trim or add anything; the app will compress, mute and loop the clip.
4. Save each clip with the exact file name shown (for example `ex_knee_push_up.mp4`). Put all clips in one folder or ZIP and hand it over.
5. Optional, for the same character in every clip: save one good frame of the man and one of the woman from your first clips, then add the matching frame in Flow's **Ingredients to Video** with the same prompt.

## Check every clip before keeping it

- The pose matches the "Correct form" lines: straight lines, joint angles and the working side are right.
- The whole body (or the upper body, where the prompt says so) is in frame for all 8 seconds.
- Red and orange appear only on the muscles listed in the prompt, not on random body parts.
- One character only; no extra or missing fingers, hands or legs; no morphing.
- No text, logos or watermarks anywhere.
- The first and last frames are in the same position, so the loop does not jump.
- Holds stay still; repetitions keep the same tempo.
